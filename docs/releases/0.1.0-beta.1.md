# BetterQuickSettings 0.1.0-beta.1

The first public **beta** of BetterQuickSettings, a native Quick Settings
replacement for Windows 11. Expect rough edges and device-specific issues.

## Choose a download

- **Setup.exe — recommended:** installs for the current user, adds a Start menu
  shortcut, and supports removal through Windows Settings → Apps. No admin
  privileges are required. A desktop shortcut is optional.
- **Portable.zip:** extract the entire archive and run `BetterQuickSettings.exe`.
  No installation is required; keep all extracted files together.

Both packages contain the same Windows x64 application and include the .NET 10
runtime. You do not need to install .NET separately. Windows 11 is required.
ARM64 emulation and unusual shell configurations have not been verified.

**Download Setup.exe or Portable.zip under Assets**, not GitHub's automatically
generated source-code archives, unless you want to build the app yourself.

## Included

- Volume, mute, audio output selection, automatic headphones, and volume feedback.
- Supported monitor brightness and Windows media controls.
- Adjustable glass, animated pages, collapsible tools, and remembered panel height.
- Multiple notes with automatic saving and draft recovery.
- A persistent file shelf and a drop balloon over the network/volume area.
- Recent screenshots, full-image previews, and drag-to-share thumbnails.
- Searchable clipboard history: up to 50 items and 32 MB of content.

Open the panel with **Win + A** or the existing network/volume area. **Shift +
click** opens the original Windows panel. Quit from the tray menu.

## Before installing or upgrading

Close any running copy, including older Ada previews. Existing notes, clipboard
history, and shelf copies remain in Local AppData; uninstalling preserves them.
Portable builds also save data in Local AppData, not in the extracted folder.

This beta is **unsigned**. Windows may show an unknown-publisher or SmartScreen
warning. Download only from this repository and verify the SHA-256 checksum;
do not disable Windows security protections.

```powershell
Get-FileHash .\BetterQuickSettings-0.1.0-beta.1-win-x64-Setup.exe -Algorithm SHA256
```

Compare the result with `SHA256SUMS.txt` in this release.

## Known limitations

- Wi-Fi, Bluetooth, and night light are Windows settings shortcuts, not toggles.
- External brightness requires DDC/CI; the built-in fallback requires one logical display.
- Virtual email attachments and linked directories are not supported by the shelf.
- Windows shell updates, mixed-DPI monitors, and hardware hot-plug need broader testing.
- Clipboard history is stored locally, not encrypted by the application. Pause
  collection before copying sensitive information; exclusion markers are honored
  only when the source application provides them.
- There is no automatic updater yet.

Please [report issues](https://github.com/lumax90/betterquicksettings/issues) with
your Windows build, display scaling, and reproduction steps. Remove personal
content from screenshots and logs before sharing.
